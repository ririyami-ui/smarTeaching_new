# PANDUAN PENCARIAN DATA BUKU KEMENDIKBUD
## Untuk Fase 1: Pengumpulan Referensi Buku

---

## 🔍 STRATEGI PENCARIAN

### 1. SUMBER UTAMA (Prioritas)

#### A. Pusatperbukuan.kemdikbud.go.id
**Cara Akses:**
1. Buka https://pusatperbukuan.kemdikbud.go.id
2. Cari "Kurikulum Merdeka" atau "Buku Teks"
3. Filter: Tingkat SMP, Tahun 2024-2025
4. Download katalog atau metadata buku

**Data yang Dicari:**
- Judul buku lengkap
- ISBN (13 digit)
- Penerbit
- Tahun terbit
- Daftar isi (bab & halaman)
- Durasi pembelajaran per bab

#### C. Sekolah Pilot Kurikulum Merdeka
**Cara Menemukan:**
1. Cari "Sekolah Pilot Kurikulum Merdeka" + nama provinsi
2. Hubungi guru mata pelajaran
3. Minta copy buku atau metadata

**Pertanyaan untuk Guru:**
- "Buku apa yang Anda gunakan untuk Kurikulum Merdeka?"
- "Bisa saya lihat daftar isi dan halaman per bab?"
- "Berapa durasi pembelajaran per bab?"
- "Ada praktik/eksperimen apa saja?"

## 📋 CHECKLIST PENCARIAN PER BUKU

Gunakan checklist ini untuk setiap buku yang dicari:

```
BUKU: [Nama Buku]
Mata Pelajaran: [Matematika/B.Indonesia/IPA]
Kelas: [7/8/9]
Semester: [Ganjil/Genap]

METADATA:
- [ ] Judul lengkap
- [ ] Penerbit
- [ ] ISBN
- [ ] Tahun terbit
- [ ] Penulis
- [ ] Halaman total
- [ ] Harga (opsional)

DAFTAR ISI:
- [ ] Bab 1: [Judul] - Halaman [X-Y] - Durasi [Z] jam
- [ ] Bab 2: [Judul] - Halaman [X-Y] - Durasi [Z] jam
- [ ] Bab 3: [Judul] - Halaman [X-Y] - Durasi [Z] jam
- [ ] [dst...]

KONTEN KHUSUS:
- [ ] Praktik/Eksperimen (untuk IPA)
- [ ] Contoh Teks (untuk B.Indonesia)
- [ ] Soal Latihan
- [ ] Kunci Jawaban

SUMBER DITEMUKAN:
- [ ] Pusatperbukuan.kemdikbud.go.id
- [ ] Penerbit: [Nama]
- [ ] Sekolah: [Nama]
- [ ] Guru: [Nama]
- [ ] Lainnya: [Sumber]

STATUS: ✅ Lengkap / ⏳ Partial / ❌ Belum

CATATAN:
[Catatan penting]
```

## 📞 TEMPLATE EMAIL/CHAT UNTUK MENGHUBUNGI

### Template 1: Untuk Guru

```
Assalamu'alaikum Pak/Bu [Nama Guru],

Saya sedang mengumpulkan data referensi buku teks Kurikulum Merdeka 
untuk SMP. Saya ingin menanyakan:

1. Buku apa yang Anda gunakan untuk mengajar [Mata Pelajaran] 
   Kelas [7/8/9]?
2. Bisa saya lihat daftar isi dan halaman per bab?
3. Berapa durasi pembelajaran untuk setiap bab?
4. Ada praktik/eksperimen apa saja? (untuk IPA)
5. Contoh teks apa yang digunakan? (untuk B.Indonesia)

Terima kasih atas bantuannya.

Salam,
[Nama Anda]
```

### Template 2: Untuk Penerbit

```
Halo,

Saya sedang mengumpulkan metadata buku teks Kurikulum Merdeka SMP 
untuk keperluan pengembangan sistem pembelajaran.

Saya membutuhkan informasi:
1. Daftar buku Kurikulum Merdeka SMP yang Anda terbitkan
2. ISBN, judul, dan tahun terbit
3. Daftar isi (bab & halaman)
4. Durasi pembelajaran per bab

Bisa dikirim dalam format Excel atau PDF?

Terima kasih,
[Nama Anda]
```

### Template 3: Untuk Sekolah Pilot

```
Assalamu'alaikum,

Saya mengetahui sekolah Anda adalah sekolah pilot Kurikulum Merdeka. 
Saya ingin menanyakan:

1. Buku teks apa yang digunakan untuk [Mata Pelajaran]?
2. Bisa saya mendapatkan copy atau foto daftar isi?
3. Siapa guru [Mata Pelajaran] yang bisa saya hubungi?

Terima kasih atas kerja samanya.

Salam,
[Nama Anda]
```

## ⏱️ ESTIMASI WAKTU PENCARIAN

| Aktivitas | Waktu | Catatan |
|-----------|-------|---------|
| Cari 1 buku (lengkap) | 30-60 menit | Termasuk verifikasi |
| Hubungi 1 guru | 15-30 menit | Tunggu balasan |
| Hubungi 1 penerbit | 30-60 menit | Tunggu balasan |
| Dokumentasikan 1 buku | 15-20 menit | Input ke template |

**Total untuk 18 buku (Prioritas 1):**
- Optimis: 18 × 30 menit = 9 jam
- Realistis: 18 × 45 menit = 13.5 jam
- Pesimis: 18 × 60 menit = 18 jam

---

## 🎯 TIPS EFISIEN

1. **Paralel:** Hubungi guru, penerbit, sekolah secara bersamaan
2. **Batch:** Cari semua buku Matematika dulu, baru B.Indonesia, dst
3. **Template:** Gunakan template yang sama untuk semua buku
4. **Dokumentasi:** Catat sumber data untuk setiap buku
5. **Follow-up:** Set reminder untuk follow-up jika belum ada balasan
